Phones and tablets

The app works the same on a phone, with a layout made for touch.

Importing on a phone

  • Choose recordings… opens the file picker; select all of the day's VBO/RCZ files. There is no folder picker on a phone.
  • On iPhone the picker shows every file; files that are not recordings are listed under Import notes.

Sharing from RaceChrono

  1. In RaceChrono, open the session and export it as VBO (and/or RCZ).
  2. Choose Share, then FlappedEar Telemetry.
  3. The app opens and adds the file to today's day:
    • If a day is open, the recording is added to it as the next session.
    • Otherwise, if you worked on a day with recordings from the same date in the last 24 hours (unsaved, or the newest saved day), that day opens with the new session added.
    • Otherwise the app imports the file as a new day and opens it. If another day has unsaved changes, the import stays on Import a day next to the offer to restore that day, so nothing is replaced.

This works on Android and iOS, also when the app was closed.

Layout

  • Below 900 points of width (a phone, or a tablet held upright) the day page has two tabs, Results and Laps. Wider screens show both side by side.
  • The lap page and the comparison stack the map, charts and cards in one scrolling column.
  • Maps zoom with a pinch. Charts follow your finger.

Saved days on a phone

Days are saved inside the app (no save dialog) and opened from a list. Uninstalling the app deletes them. See Saving and opening days.
