Importing sessions

The app opens on Import sessions. Give it each session's recording as you drive, or a whole day at once, and it prepares the sessions, laps and analysis on its own.

What you can import

  • VBO and RCZ recordings, such as RaceChrono exports. Other files are skipped and listed under Import notes.
  • Up to 64 recordings at a time.
  • When the same drive was exported as both VBO and RCZ, the app uses the VBO and keeps the RCZ as its alternative source, combined with it as described in VBO and RCZ of one session. A file with the same content as another is imported once.

Where the sessions go

You do not choose a day: the app does. Recordings you pick or drop go to the day you worked on last, when it was in the last 24 hours and has recordings from the same date:

  • the saved day you just left on Import sessions;
  • otherwise the day with unsaved changes kept for recovery;
  • otherwise the newest day saved in the app (on a phone or tablet).

The new sessions are added to that day and it opens. A saved day is saved again in its file with them. Otherwise the recordings are imported as a new day, which opens by itself. A folder is always imported as a new day.

A new day never replaces unsaved changes kept for recovery: while there are any, the new day stays on Import sessions with an Open the day button instead, so you can restore or save the other day first.

So at the track, tap Import sessions… after each session and pick only the new recording: it becomes the next session of the day. The same happens when you share a recording from RaceChrono on a phone (see Sharing from RaceChrono), or use Add recordings on an open day (see Adding a session).

Reviewing the files

The import is automatic: nothing asks for your approval. To decide yourself what happens to each file, open the day and choose More (⋮) › Add and review recordings… (see Adding with a review). The files are read, and before anything is added Review the import lists every file found:

  • Each file shows its length (minutes:seconds) and its complete laps. A duplicate says which file has the same content, and a file that could not be read says why; neither can be imported.
  • Choose for each file:
    • Import as a new session: the file becomes a session of its own.
    • Skip this file: it is not imported.
    • Same run as …: the file is another recording of a session you import, for example the RCZ of a VBO. The session's laps come from the file you link to; this file is kept with it as its alternative recording and combined with it as described in VBO and RCZ of one session. This replaces the automatic pairing, also the other way round: link the VBO to the RCZ and the RCZ supplies the laps. A session keeps one other recording.
  • Possibly the same run as …: the GPS traces agree. marks two exports whose GPS traces match. It is a hint, not a choice.
  • The choices start as the automatic import would make them, so Import without changes gives the same day. The bottom line counts the new sessions, or says why the choices cannot be imported, for example Choose at least one file to import.
  • Import reads the files again and imports them as chosen. If they changed since the review (a file was replaced, or a folder has other files now), nothing is imported: The recordings changed after the review, so nothing was imported. Review them again.
  • Closing the review (✕) imports nothing: Import cancelled. Nothing was imported.

A single file can be reviewed too. Recordings shared from RaceChrono on a phone are never reviewed: they are added at once, as described in Sharing from RaceChrono.

The day file has no place to say that two recordings are still to be combined, and when a day opens the app combines only a VBO session's RCZ by itself. So when you link any other pair (an RCZ that supplies the laps with its VBO, or two VBOs, say) and save the day while they are still being lined up, saving waits until that is done, and the file records how they are combined. Meanwhile the day cannot be left: Wait until the recordings are lined up and the day is saved. If lining them up fails, nothing is combined, and the session shows it as the day will show it when it opens again: an RCZ session's VBO is kept beside it and not combined (Check clock tries again); any other pair stays in the day file with its session but is not shown or used.

While it imports

While new sessions are added to the day you worked on last, or a day is opened, the page says Opening the day…. A new day shows Looking for recordings…, then Preparing recording X of N… with a progress bar. Cancel stops at once and imports nothing; the page then says Import cancelled. Nothing was imported. You cannot start a second import while one runs.

If nothing could be imported, a panel with a red mark says why, for example No recording could be imported., and suggests choosing the recordings again, or other ones. The notes under it say what was wrong with each file.

The result

When it is done, the day opens: the day results, with Save (the disk icon) in the toolbar. When you go back, Import sessions shows the day you left at the top: its name, whether it is saved (Saved as …) or not yet (Not saved yet; changes kept from …), Open the day to go back to it, Discard… for unsaved changes (see Restoring unsaved work), and its sessions:

  • Session N, numbered in the order the sessions were recorded.
  • Under it, the lap count, for example 7 laps, or why it has no laps, for example No laps: the recording has no start/finish line.
  • On the right, the session's Best ranked lap time, as on the day results; the session with the best lap of the day is in bold purple. A session on another track layout shows its fastest lap.

The day you left is listed while the app stays open. After the app was closed, a day with unsaved changes shows as described in Restoring unsaved work, and a saved day is under Open a saved day….

If the new day could not open by itself, because another day has unsaved changes, the page instead says how many sessions were imported, lists them the same way, and offers Open the day.

Import notes

Anything that was skipped or combined is listed under Import notes, one line per file, for example a file that is not a recording, a duplicate, or a VBO and RCZ of the same drive. When the day opens, the notes show at the bottom of the day for a few seconds (✕ closes them); when it does not, they are listed under the sessions.

How laps are found

Laps come from the start/finish line saved in the recording (the RaceChrono track's start line) and the GPS trace:

  • OUT: from the start of the recording to the first crossing.
  • LAP n: between two crossings.
  • IN: from the last crossing to the end of the recording.
  • UNKNOWN: the whole recording, when the line was never crossed.

The start/finish line cannot be placed by hand. If a session has no laps, see No laps.

Restoring unsaved work

While you work on a day that is not saved, the app keeps a copy of it. If the app closed before you saved, Import sessions shows <day> has unsaved changes from … with two buttons:

  • Restore reopens the day with your changes.
  • Discard… deletes the copy after asking. Your recordings and saved days are not touched.

The copy is updated half a second after each change, and straight away when you switch to another app or quit. If the app crashes or is stopped within that half second, the very last change can be missing from the copy, so save the day to be sure.

Only one unsaved day is kept: working on another unsaved day replaces the copy. A day you just imported and never saved counts as unsaved: when you go back from it, it is the day listed at the top, with Open the day (which restores it) and Discard….
