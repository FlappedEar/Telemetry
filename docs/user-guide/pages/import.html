Importing a day

The app opens on Import a day. Give it the day's recordings and it prepares the sessions, laps and analysis on its own.

What you can import

  • VBO and RCZ recordings, such as RaceChrono exports. Other files are skipped and listed under Import notes.
  • Up to 64 recordings at a time.
  • When the same drive was exported as both VBO and RCZ, the app uses the VBO and keeps the RCZ as its alternative source, combined with it as described in VBO and RCZ of one session. A file with the same content as another is imported once.

Reviewing the files before importing

The import is automatic: nothing asks for your approval. To decide yourself what happens to each file, tick Review the files before importing, then choose the recordings or a folder, or drop them. The files are read, and before anything is imported Review the import lists every file found:

  • Each file shows its length (minutes:seconds) and its complete laps. A duplicate says which file has the same content, and a file that could not be read says why; neither can be imported.
  • Choose for each file:
    • Import as a new session: the file becomes a session of its own.
    • Skip this file: it is not imported.
    • Same run as …: the file is another recording of a session you import, for example the RCZ of a VBO. The session's laps come from the file you link to; this file is kept with it as its alternative recording and combined with it as described in VBO and RCZ of one session. This replaces the automatic pairing, also the other way round: link the VBO to the RCZ and the RCZ supplies the laps. A session keeps one other recording.
  • Possibly the same run as …: the GPS traces agree. marks two exports whose GPS traces match. It is a hint, not a choice.
  • The choices start as the automatic import would make them, so Import without changes gives the same day. The bottom line counts the new sessions, or says why the choices cannot be imported, for example Choose at least one file to import.
  • Import reads the files again and imports them as chosen. If they changed since the review (a file was replaced, or a folder has other files now), nothing is imported: The recordings changed after the review, so nothing was imported. Review them again.
  • Closing the review (✕) imports nothing: Import cancelled. Nothing was imported.

The box is cleared after each review, so the next import is automatic again. A single file can be reviewed too. Recordings shared from RaceChrono on a phone are never reviewed: they are added at once, as described in Sharing from RaceChrono. To review recordings for a day that is open, see Adding with a review.

The day file has no place to say that two recordings are still to be combined, and when a day opens the app combines only a VBO session's RCZ by itself. So when you link any other pair (an RCZ that supplies the laps with its VBO, or two VBOs, say) and save the day while they are still being lined up, saving waits until that is done, and the file records how they are combined. Meanwhile the day cannot be left: Wait until the recordings are lined up and the day is saved. If lining them up fails, nothing is combined, and the session shows it as the day will show it when it opens again: an RCZ session's VBO is kept beside it and not combined (Check clock tries again); any other pair stays in the day file with its session but is not shown or used.

While it imports

The page shows Looking for recordings…, then Preparing recording X of N… with a progress bar. Cancel stops at once and imports nothing. You cannot start a second import while one runs.

The result

When it is done, the page says how many sessions were imported and lists each one:

  • Session N, numbered in the order the sessions were recorded.
  • Under it, the lap count and best lap, for example 7 laps · best 1:49.898, or why it has no laps, for example No laps: the recording has no start/finish line.

Tap Show the day's results to open the day results. From then on the day is kept as a saved day or as unsaved work (see Restoring unsaved work), so the import list is cleared when you come back.

Import notes

Anything that was skipped or combined is listed under Import notes, one line per file, for example a file that is not a recording, a duplicate, or a VBO and RCZ of the same drive.

How laps are found

Laps come from the start/finish line saved in the recording (the RaceChrono track's start line) and the GPS trace:

  • OUT: from the start of the recording to the first crossing.
  • LAP n: between two crossings.
  • IN: from the last crossing to the end of the recording.
  • UNKNOWN: the whole recording, when the line was never crossed.

The start/finish line cannot be placed by hand. If a session has no laps, see No laps.

Restoring unsaved work

While you work on a day that is not saved, the app keeps a copy of it. If the app closed before you saved, Import a day shows <day> has unsaved changes from … with two buttons:

  • Restore reopens the day with your changes.
  • Discard… deletes the copy after asking. Your recordings and saved days are not touched.

The copy is updated half a second after each change, and straight away when you switch to another app or quit. If the app crashes or is stopped within that half second, the very last change can be missing from the copy, so save the day to be sure.

Only one unsaved day is kept: working on another unsaved day replaces the copy. A day you just imported and never saved counts as unsaved, so the banner also appears when you go back from its results.
