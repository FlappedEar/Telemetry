Working with FlappedEar Overlays

FlappedEar Overlays is the macOS app for onboard video with telemetry overlays. Telemetry is the analysis app for every platform, with no video. They share one day file.

One file for both apps

Both apps read and write the same .fetproject format. A day saved by either app opens in the other, with:

  • the sessions and their recordings,
  • approved and edited segments,
  • excluded laps and their reasons,
  • the day's name, and each session's name, notes, conditions and setup changes (edited in either app),
  • each session's weather (Telemetry looks it up; Overlays keeps it in the file unchanged),
  • each session's setup: tyre pressures, tyres and fuel (entered in Telemetry; Overlays keeps it in the file unchanged but does not show it),
  • each session's primary recording, and how its VBO and RCZ were combined or kept apart (Overlays shows both in Run details),
  • the group of laps shown.

Telemetry keeps everything that belongs to Overlays (video, sync, overlay layouts) unchanged when it saves, so you can go back and forth.

A typical day

  1. After the session, import the RaceChrono exports in Telemetry on your phone and look at the laps between sessions. The day is kept in the phone's library by itself.
  2. At home, import the same recordings in Telemetry on the Mac. The day is kept in the Mac's library.
  3. Choose ⋮ › Export for Overlays…, then open that .fetproject in Overlays to add the onboard video and render overlays.

Each device keeps its own library; copying a library to another device is not available yet. The exported file points to the recordings, so they must stay where they were when you exported; see Find recordings in a folder.

The Overlays guide is at flappedear.github.io/Overlay.
