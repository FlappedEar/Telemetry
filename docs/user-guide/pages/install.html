Install

There is no app store release yet. Android installs from a build file; macOS runs from the source code.

Android (Pixel)

  1. On a computer signed in to GitHub, open the newest green run of the CI workflow on the main branch: Actions, branch main.
  2. At the bottom of the run, download the artifact flappedear-telemetry-android-<commit> and unzip it. Inside is app-release.apk.
  3. Copy the APK to the phone (USB, Google Drive or email).
  4. Open it from the Files app. Allow installs from that app when Android asks, then tap Install. If Play Protect warns about an unknown app, choose Install anyway.
  5. Open FlappedEar Telemetry. It starts on Import a day.

Always take the APK from a run on main. Those builds share one signing key, so a newer one installs over the old one and keeps your saved days. Builds from pull requests are for testing only.

If Android refuses an update because the app "is not installed" or the signature differs, do not uninstall yet: uninstalling deletes the days kept in the app. Save them elsewhere first.

macOS

There is no signed Mac download yet. With Flutter 3.47.6 installed, run it from a checkout of the repository:

flutter pub get
flutter run -d macos

iPhone and iPad

The iOS app is built and tested in the simulator only, until there is an Apple developer account. It cannot be installed on a phone yet.

Windows

The app builds for Windows, but there is no download yet.

Map backgrounds

Street maps (OpenStreetMap) work in every build. Satellite imagery (MapTiler) is only offered by builds made with a MapTiler key; the Android builds from CI have one. Tiles need a network connection the first time a track is shown; see Map background.

Language

The app follows the language of your phone or computer. It speaks English and Polish; on a device set to any other language it uses English. There is no language setting in the app; to switch, change the device language.

Numbers use a decimal point in every language, as on timing screens: a lap reads 1:49.898 in Polish too.

The Polish translation is in progress. Most screens are still in English; they are translated one at a time.
