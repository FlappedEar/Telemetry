Install

There is no app store release yet. Android, macOS and Windows download from the project's GitHub Releases.

Each release on the Releases page has, under Assets:

  • FlappedEar-Telemetry-<version>-android.apk: the Android app.
  • FlappedEar-Telemetry-<version>-macos.zip: the Mac app.
  • FlappedEar-Telemetry-<version>-windows.zip: the Windows app.
  • SHA256SUMS.txt: checksums of the files above.

Android (Pixel)

  1. On the phone, open the Releases page and tap the .apk under Assets of the newest release.
  2. Open the downloaded file. Allow installs from that app when Android asks, then tap Install. If Play Protect warns about an unknown app, choose Install anyway.
  3. Open FlappedEar Telemetry. It starts on Home.

Releases and the builds from main share one signing key, so a newer one installs over the old one and keeps your saved days.

Builds newer than the last release: on a computer signed in to GitHub, open the newest green run of the CI workflow on branch main and download the artifact flappedear-telemetry-android-<commit>. Inside the zip is app-release.apk. Builds from pull requests are for testing only.

If Android refuses an update because the app "is not installed" or the signature differs, do not uninstall yet: uninstalling deletes the days kept in the app. Save them elsewhere first.

macOS

The app needs macOS 12.0 or later.

  1. Download the -macos.zip from the newest release and open it. Move FlappedEar Telemetry to Applications.
  2. Open the app. The Mac download is not notarized by Apple yet, so the first time macOS refuses to open it:
    • macOS 15 and later: click Done, open System Settings > Privacy & Security, scroll down to the message about FlappedEar Telemetry and click Open Anyway, then confirm with your password or Touch ID.
    • macOS 12 to 14: Control-click the app, choose Open, then Open again.
  3. After that it opens normally. A newer release replaces the app in Applications; your saved days stay where you saved them.

To run the newest code instead, install Flutter 3.47.6 and run it from a checkout of the repository:

flutter pub get
flutter run -d macos

iPhone and iPad

The iOS app is built and tested in the simulator only, until there is an Apple developer account. It cannot be installed on a phone yet.

Windows

The app needs Windows 10 or 11 (64-bit).

  1. Download the -windows.zip from the newest release. Right-click it, choose Extract All and pick a folder you keep, such as Documents. Do not run it from inside the zip.
  2. Open the extracted folder and start telemetry.exe. The Windows download is not signed yet, so the first time Windows SmartScreen may show Windows protected your PC: click More info, then Run anyway.
  3. A newer release is a new folder: extract it the same way and start the new telemetry.exe. Your saved days stay where you saved them. You can delete the old folder.

To run the newest code instead, install Flutter 3.47.6 and run flutter run -d windows from a checkout of the repository.

Updates

When it starts, the app asks GitHub whether a newer release is out, at most once a day, and fetches the newest circuit list. If one is, a message says so; tap Details. To check at any time, choose Check for updates in the ⋮ menu on Home, or open Settings (the gear in the toolbar; on the day page on a narrow screen, such as a phone, in the ⋮ menu): Updates is its first section and shows the version you have. Turn off Check for a new version when the app starts there to stop the check on launch; the circuit list then stays as it is until you choose Update the circuit list. Only requests for the releases, their files and the circuit list go to GitHub; none of your recordings or settings are sent. Without a connection, or when GitHub has had too many checks from your network, the check on launch says nothing and tries again next time.

  • Android: tap Download and install. The first time, Android asks you to allow FlappedEar Telemetry to install apps: turn it on in the settings that open, go back and tap Continue (if the app started again, open Settings and tap Check for updates). The app then downloads the APK, checks it against the release's SHA256SUMS.txt and opens Android's installer; confirm the update there. Your saved days stay.
  • Mac: tap Download and choose where to save the zip (Downloads is suggested). The app checks it against SHA256SUMS.txt and shows it in Finder. Open it and move FlappedEar Telemetry to Applications, replacing the old one. macOS refuses the first start of the new copy, as after the first install: allow it as described in macOS.
  • Windows: the app only says that a newer version exists; What's new opens the release on GitHub. Download the -windows.zip there and extract it as described in Windows.
  • iPhone and iPad: the releases have no download for these yet, so the app only says that a newer version exists; What's new opens the release on GitHub.

A download that does not match the release's checksum is deleted and never installed.

Map backgrounds

Street maps (OpenStreetMap) work in every build. Satellite imagery (MapTiler) is only offered by builds made with a MapTiler key; the releases and the Android builds from CI have one, a Mac or Windows build you run yourself does not. On iPhone, iPad and Mac the layers button also offers Apple Maps, which needs no key; other platforms do not have it. Maps need a network connection the first time a track is shown; see Map background.

FlappedEar Telemetry is free and its source code is under the Apache License 2.0. To see the licences of the app and of the software it uses, with the map credits (OpenStreetMap and MapTiler) and the weather credit (Open-Meteo.com), open Settings (the gear in the toolbar; on the day page on a narrow screen, such as a phone, in the ⋮ menu) and choose Open-source licences.

Language

The app follows the language of your phone or computer. It speaks English and Polish; on a device set to any other language it uses English. There is no language setting in the app; to switch, change the device language.

Numbers use a decimal point in every language, as on timing screens: a lap reads 1:49.898 in Polish too.

The Polish translation is new. If a phrase reads oddly, report it as described in Reporting a problem.
