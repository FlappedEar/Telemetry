## FlappedEar Telemetry 0.3.0 (pre-release)

The app is now also a download for Windows, and the version moves to 0.3. It installs over 0.2.31 and earlier versions and over Android builds from `main`, and keeps your saved days. From 0.2.6 on, **Settings › Check for updates** finds this release.

### Windows app

- Each release now has a `-windows.zip` with the Windows app (Windows 10 or 11, 64-bit). Extract it to a folder you keep and start `telemetry.exe`.
- It is not signed yet, so Windows SmartScreen may warn the first time: **More info**, then **Run anyway**. The install page of the user guide has the steps.
- The app does not update itself on Windows: **Check for updates** says that a newer version exists and opens its release page.

### Also in this build

- The Polish user guide has had its wording corrected, and its install page covers Windows.

### Install

Android: the `.apk` below. macOS 12 or later: the `-macos.zip` below; it is not notarized; the install page says how to open it the first time. Windows 10 or 11: the `-windows.zip` below; it is not signed. Check downloads against `SHA256SUMS.txt`.
