## FlappedEar Telemetry 0.3.0 (pre-release)

The app is now also a download for Windows, and the version moves to 0.3. It installs over 0.2.31 and earlier versions and over Android builds from `main`, and keeps your saved days. From 0.2.6 on, **Settings › Check for updates** finds this release.

### Windows app

- Each release now has a `-windows-setup.exe` installer for the Windows app (Windows 10 or 11, 64-bit). It installs for your user only, needs no administrator rights and adds a Start menu entry. A newer installer replaces the old files and keeps your saved days; removing the app from **Settings › Apps** keeps them too.
- There is also a `-windows.zip` with the same app and no installer: extract it to a folder you keep and start `telemetry.exe`.
- Neither is signed yet, so Windows SmartScreen may warn the first time: **More info**, then **Run anyway**. The install page of the user guide has the steps.
- The app does not update itself on Windows: **Check for updates** says that a newer version exists and opens its release page.

### Car, last laps

- The Car card's lines about the last laps now say what was measured, over which laps, and the result. *Strong acceleration* is now *Peak acceleration*.
- A fall of 5% or more reads for example *Peak acceleration down 6%: 0.250 g on lap 5, against 0.265 g on lap 2, the highest before it*. A smaller fall names both laps and values, with the percentage cut rather than rounded so it never reads as 5%, and when the last lap is at least as high the line says *not below*.
- A temperature counts as still rising only when it rose by 8 °C (14.4 °F) or more over the last three ranked laps. When nothing rose that much, the line says which laps it looked at, for example *Temperatures over laps 3–5: none still rising*.

### Also in this build

- The Polish user guide has had its wording corrected, and its install page covers Windows.

### Install

Android: the `.apk` below. macOS 12 or later: the `-macos.zip` below; it is not notarized; the install page says how to open it the first time. Windows 10 or 11: the `-windows-setup.exe` (or the `-windows.zip`) below; not signed. Check downloads against `SHA256SUMS.txt`.
