## FlappedEar Telemetry 0.2.1 (pre-release)

Fixes and polish on top of 0.2.0. It installs over 0.2.0, over 0.1.0 and over Android builds from `main`, and keeps your saved days.

### Easier to read

- **Large text and large screens.** With very large text on a phone, the lap page's speed legend, the corner sheet, time losses, coasting, the lap picker and Compare now wrap instead of running off the screen, lap rows grow taller, and in the segment editor the list stays in view. On a tablet or desktop the import page, day report, diagnostics, settings, segment editor and the day's lap list keep a readable width.
- **Units stay with their numbers** when a line wraps (s, m, km/h, g, bpm, %).
- On a day with one session, **Consistency** shows one row, named after the session, instead of the same value twice.
- **Calmer colours:** the start/finish gate is black on a white edge; the progression median, coach chip and label, and Corner Analyzer cursor are neutral instead of amber or green; pending segment boundaries are purple instead of orange.
- **Polish for recording errors and notes.** Messages about a recording (a file that cannot be read, size limits, missing GPS, laps that cannot be timed, combining VBO and RCZ) are now in Polish too; for a damaged file the technical detail after the sentence stays in English.

### Easier to use

- **No circuit identified? Set it.** When a day has no best lap because the circuit was not identified, it offers *Set the circuit…*, and tapping a session whose circuit was not identified opens its circuit dialog.
- **Cancel a long clock check or primary change** on a combined VBO + RCZ session.
- A recording without GPS positions now says GPS is missing, instead of saying no start/finish line was found.
- A failed or cancelled import is a banner that says what to do next.
- A failed theoretical best is shown once, with one *Calculate again*.
- On a narrow screen, such as a phone, Settings on the day page is in the ⋮ (More) menu so the day's title has room.
- *Include subfolders* can be ticked by tapping its label, and progress bars are read out by screen readers.

### More reliable

- A day can be left as soon as a waiting save has lined up its recordings, while the file is still being written.
- Asking for an import while another runs gives one clear message, the same in Polish on every screen.
