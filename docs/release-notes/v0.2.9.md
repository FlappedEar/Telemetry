## FlappedEar Telemetry 0.2.9 (pre-release)

Weather that is asked for again when the next session is added, so it fills in once the signal is back, and a guide section on using the app at the track without signal. It installs over 0.2.8 and earlier versions and over Android builds from `main`, and keeps your saved days. From 0.2.6 on, **Settings › Check for updates** finds this release.

### Weather without signal

- When a session's weather could not be looked up (no signal at the track), the app now asks again by itself when the next session is added to the day, so the weather fills in once the signal is back. **Try again** in Session details and reopening the day still ask again too.

### User guide

- **Troubleshooting › At the track without signal** says what works offline (importing or sharing a session, the results, Coach, saving and the Library) and the three things that need a connection: map backgrounds, the weather and the check for a new version.

### Install

Android: the `.apk` below. macOS 12 or later: the `-macos.zip` below; it is not notarized; the install page says how to open it the first time. Check downloads against `SHA256SUMS.txt`.
