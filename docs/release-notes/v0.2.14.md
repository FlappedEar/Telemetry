## FlappedEar Telemetry 0.2.14 (pre-release)

Earlier visits here now names the corner the day's figures are kept on, for days added from this version on. It installs over 0.2.13 and earlier versions and over Android builds from `main`, and keeps your saved days. From 0.2.6 on, **Settings › Check for updates** finds this release.

### Earlier visits here

- For a day added from this version on, the **Earlier visits here** line under each area in **Where to look next** names the corner the day's figures are kept on in your library. Before, when a later day added a corner that fitted the place better, the line for an older day could name that neighbouring corner instead.
- Days added from this version on keep which of the day's segments each corner was placed from. Days added before keep being matched as in 0.2.13, and can still name a neighbouring corner, until they are added again in this version.

### Driver profile files

- A `.feprofile` exported from this version keeps, for each corner of a session, the day's segment it was placed from. Earlier versions open these files, ignore the new field and keep it when they save, unless they measure the day's corners again.
